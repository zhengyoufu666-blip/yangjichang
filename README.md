# 🐔 养鸡场 - 智能基金投资记录系统

一个优雅的基金投资记录展示系统，专为长期投资者打造。支持云端数据同步与本地数据降级，确保随时可用。

## ✨ 核心功能

### 📊 智能数据管理
- **云端同步**：数据存储在Google Sheets，实时同步更新
- **本地降级**：网络不可用时自动切换到本地备份数据
- **一键导出**：轻松将云端数据导出到本地文件
- **完整表头**：支持10个字段的完整数据表头结构

### 🎨 优雅视觉设计
- **暖色调主题**：温馨的橙/琥珀/玫瑰金配色方案
- **现代化界面**：毛玻璃效果、流畅动画、响应式布局
- **数据可视化**：持仓饼图、收益统计、操作记录时间线
- **移动优先**：完美适配手机、平板、电脑所有设备

### 🚀 智能特性
- **实时估值**：支持基金实时估值显示
- **持仓分析**：自动计算持仓占比和分布
- **操作分类**：智能识别买入、卖出、定投等操作类型
- **风险提示**：显眼但不突兀的风险说明

## 🚀 快速开始

### 1. 基础使用
```bash
# 直接打开主页面
open index.html

# 或使用本地服务器
python -m http.server 8080
# 访问 http://localhost:8080
```

### 2. 数据源配置
系统默认使用预配置的Google Sheets API。如需使用自己的数据源：

1. 创建Google Sheets表格，包含以下工作表：
   - `定投基金`：持仓数据
   - `主动操作`：操作记录
   - `说明`：风险说明

2. 部署Google Apps Script (`Code.gs`) 提供API接口

3. 在 `app.js` 中更新 `GOOGLE_SHEET_API_URL`

### 3. 本地数据管理
当无法访问Google Sheets时（如无梯子），系统会自动切换到本地数据：

```javascript
// 导出当前数据到本地
点击页面上的"💾 导出本地数据"按钮

// 或使用可视化工具
打开 export-local-data.html → 获取数据 → 导出
```

## 📊 数据表头结构

### 定投基金工作表（10个字段）
| 字段 | 说明 | 必填 | 计算关系 |
|------|------|------|----------|
| **分类** | 基金类别（指数、科技、医疗等） | 是 | - |
| **基金代码** | 6位基金代码 | 是 | - |
| **基金名称** | 基金全称 | 是 | - |
| **近6月回报** | 涨跌幅百分比（如"+15.23%"） | 是 | - |
| **操作** | 操作建议（推荐定投、一般、风险较高、暂时别买） | 是 | - |
| **备注** | 额外说明 | 否 | - |
| **金额** | 持仓金额 | 是 | **用于计算持仓占比** |
| **累计收益** | 累计收益金额 | 否 | - |
| **基金限购** | 限购金额 | 否 | - |
| **当日估值** | 当日估值数据 | 否 | - |

### 主动操作工作表（5个字段）
| 字段 | 说明 | 必填 |
|------|------|------|
| **操作时间** | 操作日期（YYYY-MM-DD） | 是 |
| **每日定投** | 定投内容 | 是 |
| **买入操作** | 买入记录 | 否 |
| **卖出操作** | 卖出记录 | 否 |
| **当日留言** | 当日备注 | 否 |

### 说明工作表（1个字段）
| 字段 | 说明 | 必填 |
|------|------|------|
| **风险说明** | 风险提示内容 | 是 |

## 🔧 高级功能

### 本地数据降级系统
- **自动检测**：网络失败时自动重试3次
- **无缝切换**：重试失败后自动使用本地数据
- **用户提示**：显示明显的本地数据提示
- **一键重试**：提供重新连接按钮

### 数据导出工具
```bash
# 方法1：可视化导出
打开 export-local-data.html
→ 点击"获取Google Sheets数据"
→ 点击"导出到本地文件"

# 方法2：直接导出
打开 index.html
→ 等待数据加载完成
→ 点击"💾 导出本地数据"按钮
```

### 持仓分析功能
- **自动计算**：基于"金额"字段计算持仓占比
- **饼图展示**：可视化持仓分布
- **操作分类**：按操作类型分析持仓
- **排序功能**：支持按占比、收益、涨跌幅排序

## 🛠️ 技术架构

### 前端技术栈
- **纯前端**：HTML5、CSS3、原生JavaScript
- **无依赖**：不依赖任何第三方库
- **现代化**：使用ES6+特性、CSS Grid/Flexbox
- **响应式**：移动优先的响应式设计

### 数据流架构
```
Google Sheets (云端数据源)
    ↓ API调用
应用程序 (实时数据)
    ↓ 失败重试
本地数据文件 (降级方案)
    ↓ 渲染
用户界面 (完整展示)
```

### 部署选项
1. **静态托管**：GitHub Pages、Vercel、Netlify
2. **本地使用**：直接文件访问
3. **自定义部署**：任何支持静态文件的服务器

## 🚨 注意事项

### 数据安全
- 本地数据文件可能包含敏感信息
- 建议不要将包含真实数据的文件提交到公开仓库

### 网络依赖

- 无网络时可使用本地数据降级
